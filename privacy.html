Shelton Daily Health 隐私说明

本应用仅供所有者本人使用，用于读取本人授权的 WHOOP 数据并发送每日飞书私聊简报。

读取的数据

经本人授权，应用可读取恢复、身体负荷周期、睡眠、运动、个人资料及身体测量数据。

处理与存储

每日处理程序在本人 Mac 上运行。WHOOP 令牌和读取的数据保存在本机，不上传到本 GitHub 仓库。此公开网站只提供本说明和一次性授权跳转页；跳转页不会主动向其他服务发送授权结果。

飞书消息

简报通过飞书开放平台发送到本人私聊，因此简报内容会经过飞书服务。应用不会出售数据，也不会主动发送给其他人。

撤销与删除

可以在 WHOOP 中撤销授权，并删除本机保存的令牌和数据。停用本机定时任务可停止推送。

联系

问题可通过本项目的 GitHub Issues 联系。
